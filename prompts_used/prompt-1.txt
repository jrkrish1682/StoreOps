====================================================
ARCHITECTURE RULES
====================================================

Mandatory 3-layer architecture.

Routes
    -> Service
        -> Repository

Rules:

1. Routes may call Services only.

2. Services may call Repositories only.

3. Repositories must not call Services.

4. Repositories must not call external services.

5. No business logic in Routes.

6. Cross-module repository access is prohibited.

Example:

ActivitiesService cannot import ProgrammesRepository.

7. Read operations may use another module's Service.

8. Cross-module side effects must use EventBus only.

Example:

Activities module must publish event:

TASK_COMPLETED

Alerts module consumes event.

No direct AlertsService invocation.

====================================================
ERROR HANDLING
====================================================

Create AppError hierarchy.

AppError:

- error_code
- message
- status_code

Create:

ValidationError
NotFoundError
BusinessRuleViolationError

Never use:

raise Exception(...)
raise RuntimeError(...)

Services must always raise AppError types.
